# MSYS2 packages for the Windows builds (UCRT64 on x86_64, CLANGARM64 on arm64).
#
#   <package>|<archs>|<FFmpeg configure flags>
#
# <package> is the name without the mingw-w64-<env>- prefix. <archs> is "all",
# "x86_64" or "arm64". The flags are only passed to FFmpeg's configure when the
# package was actually installed, so a package that is missing for an
# architecture (or that failed to install) only removes its own feature.
# Packages without flags are build tools or dependencies of the ones below.
#
# FFmpeg allows exactly one TLS backend: the builds use GnuTLS (same backend
# as the Linux build; it resolves the Windows certificate store through
# CryptoAPI, so no CA bundle needs shipping). No OpenSSL/Schannel flag.
#
# Libraries that MSYS2 does not package, or only ships as DLLs, are built from
# source by scripts/common/extras-recipes.sh.
